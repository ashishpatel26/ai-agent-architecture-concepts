# Changelog

## [2.0.0] - 2026-09-18

### Expanded architecture reference

- Replaced short topic notes with 100 independently maintained architecture lessons covering production progression, components, runtime, illustrative enterprise cases, failures, tradeoffs, checklists, related concepts, and primary references. Original numbering, titles, and five-domain organization remain intact.
- Added 12 clearly separated advanced lessons on protocol boundaries, evaluation, durable execution, sandboxing, identity, event history, residency, multimodal evidence, resource budgets, memory lifecycle, human handoffs, and supply chain security.
- Added 28 industry blueprints with specialist teams, tools, authority limits, enterprise systems, recovery paths, controls, metric definitions, and staged rollout criteria. Cases are illustrative designs rather than reported deployments or promised outcomes.
- Added 190 authored Mermaid diagrams with light/dark styling, captions, source inspection, copy, zoom, fullscreen, and SVG download.

### Discovery and learning

- Redesigned the welcome page with a navy and mint architecture canvas, lifecycle guidance, five domains, learning paths, industry entry points, and the complete 100-topic index.
- Added an architecture studio for selecting any of the 28 industries, inspecting agents, stepping through runtime flows, exploring failures, and comparing two industries.
- Expanded global full-text search to all 140 guides, including architecture prose, components, keywords, and use cases.
- Added documentation tables of contents and persistent production checklists; retained bookmarks, progress export, self-assessed practice, themes, and legacy link compatibility. Learning paths now include an advanced route.

### Publishing and validation

- Added 155 generated HTML routes with complete readable content, embedded guide data, unique metadata, canonical URLs, and a sitemap for direct links and static hosting.
- Added structured content validation for the complete collection, source preservation, depth, references, related links, unique diagrams, and generated search/catalog parity, plus dedicated browser diagram and interaction validation scripts.
- Updated the downloadable curriculum and published Hindi summaries to vendor-neutral terminology. The supplied original Markdown remains unchanged.
- Retained GitHub Pages publishing from `main/docs` at the existing project URL, with locally bundled fonts and no model credentials or backend requirement.

## [1.0.0] - 2026-09-18
