# Architect Atlas design system

## Direction

A calm, editorial field guide for complex AI architecture. Warm ivory surfaces, forest-green primary actions, muted domain colors, and visible connections make the content inviting without hiding its technical depth.

## Typography

- Manrope: headings and prominent statistics.
- DM Sans: body copy, navigation, diagrams, and controls.
- System sans-serif fallbacks when external fonts cannot load.
- Sentence case, descriptive labels, and short paragraphs.

## Color

- Canvas: `#f9faf7`
- Sidebar: `#f1f3ed`
- Surfaces: `#ffffff`
- Primary ink: `#283a30`
- Forest action: `#264d38`
- Borders: `#e3e7de`
- Domains: green for agents, lavender for governance, ochre for resilience, blue for retrieval, rose for infrastructure.
- Dark theme changes surfaces and domain tokens while retaining the same semantic roles.

## Components and behavior

Fixed workspace navigation on desktop, a dismissible drawer on mobile, global keyboard search, understated cards, and dotted architecture canvases. Primary actions use solid forest green; secondary actions use outlined or text treatments. Show user progress only from actual local state.

Every diagram is accompanied by text. The hero uses a branching architecture; each topic presents a named four-stage conceptual flow. Diagram stages are keyboard accessible, with explicit play, pause, reset, and next-step controls. Animation never starts automatically. Respect reduced motion.

## Content rules

Keep all original topic identities and Hindi explanations. Explain concepts in English without guaranteed performance claims. Distinguish conceptual diagrams, estimates, and self-assessed practice from measured performance. Make limitations and tradeoffs part of the lesson.
