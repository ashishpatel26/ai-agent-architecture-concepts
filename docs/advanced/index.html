Advanced collection

Extensions 101–112 supplement the original 100 concepts.

101 — Model Context Protocol (MCP)

Standardize how agent hosts discover and invoke external capabilities while keeping trust, authorization, and business policy explicit.

102 — Agent Evaluation & Regression Suites

Evaluate complete agent behavior across task outcomes, tool effects, authorization, cost, and failure recovery before releasing changes.

103 — Durable Workflow Execution

Preserve business progress across process crashes, long waits, retries, and human approvals without duplicating external effects.

104 — Agent Sandboxing & Capability Isolation

Constrain agent-executed code and tools through independent process, filesystem, network, credential, and resource boundaries.

105 — Agent Identity & Delegated Authorization

Represent who requested an agent action, which workload performs it, and the exact authority delegated to each downstream operation.

106 — Event Sourcing for Agent Workflows

Represent business progress as an ordered history of accepted events so state, approvals, and effects can be reconstructed and audited.

107 — Data Residency & Tenant Isolation

Control where tenant information is processed and retained, and prevent cross-tenant access across every derived artifact and operational surface.

108 — Multimodal Agent Pipelines

Combine text, images, audio, video, and structured observations while preserving modality-specific evidence and uncertainty.

109 — Agent Budgeting & Admission Control

Reserve and enforce task-level limits for model tokens, tool calls, concurrency, elapsed time, and downstream load before work begins.

110 — Memory Lifecycle & Forgetting

Govern how agent memories are created, corrected, expired, and removed across source records, summaries, embeddings, caches, and backups.

111 — Agent-to-Human Handoffs

Transfer unresolved work with evidence, authority, ownership, and resumption conditions so a human can take effective control.

112 — Agent Supply Chain Security

Track and verify the origin, integrity, permissions, and release compatibility of models, prompts, tools, connectors, and agent dependencies.
